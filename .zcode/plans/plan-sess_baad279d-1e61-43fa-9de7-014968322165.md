# CRM Imobile — clienți + imobile + trimitere WhatsApp

Construim pe aplicația existentă (WA-AKG): adăugăm un modul CRM nou care reutilizează motorul WhatsApp deja existent (sesiune Baileys conectată prin QR) pentru trimiterea imobilelor cu poze și vizualizarea răspunsurilor clienților.

## 1. Modele Prisma (`prisma/schema.prisma`) + migrare

Trei modele noi, legate de utilizatorul curent (fiecare owner are propriile date):

- **CrmClient**: `id, userId, name, email?, phone` (normalizat: doar cifre cu prefix de țară, ex. `40740123456`), timestamps
- **CrmProperty**: `id, userId, name, description?, price?, currency` (default `EUR`), `images Json` (listă de fișiere încărcate), timestamps
- **PropertySend** (istoric trimiteri): `id, clientId, propertyId, sessionId` (sesiunea WA folosită), `status` (SENT/FAILED), `error?`, `sentAt`

Migrare: `npx prisma migrate dev --name add_crm_models` (necesită MySQL pornit + `DATABASE_URL` în `.env`).

## 2. Helper telefon → JID

`src/lib/crm.ts`: `normalizePhone()` — curăță `+`, spații, cratime; acceptă `0740...` (adaugă `40` implicit) sau număr internațional complet; întoarce JID-ul WhatsApp (`40740123456@s.whatsapp.net`).

## 3. API-uri noi (`src/app/api/crm/...`)

Urmează pattern-urile existente (`getAuthenticatedUser`, zod, format NextResponse):

| Ruta | Ce face |
|---|---|
| `GET/POST /api/crm/clients`, `PATCH/DELETE /api/crm/clients/[id]` | CRUD clienți |
| `GET/POST /api/crm/properties`, `PATCH/DELETE /api/crm/properties/[id]` | CRUD imobile |
| `POST /api/crm/properties/[id]/images` | upload poze (multipart) → salvate în `data/media/crm/` |
| `GET /api/crm/images/[filename]` | servește poza (protejat cu auth) |
| `POST /api/crm/send` | trimite imobilul la clienți (detaliu mai jos) |
| `GET /api/crm/clients/[id]/conversation?sessionId=` | firul complet de mesaje cu clientul |

**Trimiterea** (`/api/crm/send`): primește `{propertyId, clientIds[], sessionId, message?}` → verifică sesiunea e CONNECTED → compune mesajul (template editabil: 🏠 nume + descriere + 💰 preț) → prima poză se trimite cu `ChatService.sendMediaMessage(..., 'image', ..., caption)` (poza cu textul dedesubt), restul pozelor separat → Text simplu dacă imobilul nu are poze → creează rânduri `PropertySend` per client. Întârziere ~2s între clienți (anti-ban, ca la broadcast).

**Conversația**: interoghează `Message` existent după `remoteJid = JID-ul clientului` — mesajele trimise (`fromMe=true`) și răspunsurile primite sunt deja salvate automat de motorul existent, deci firul se compune fără logică nouă de primire.

## 4. Pagina UI: `/dashboard/crm` (în română)

O singură pagină cu două tab-uri (shadcn Tabs):

- **Tab Clienți**: tabel nume / email / telefon + butoane editare, ștergere, „Conversație"
- **Tab Imobile**: tabel thumbnail / nume / descriere / preț (formatat ro-RO cu valută) + editare, ștergere, buton **„Trimite"**
- Dialoguri Add/Edit cu react-hook-form + zod (pattern existent), upload poze cu preview
- **Dialog „Trimite"**: selectezi clienți (bifă multiplă) + sesiunea WhatsApp (doar cele CONNECTED), mesaj precompletat dar editabil, previzualizare poze, trimitere cu toast per client
- **Drawer Conversație** per client: bule mesaje (trimise la dreapta, răspunsuri la stânga), poze miniatură, refresh automat la ~10s cât e deschis

## 5. Navigare

Adaug în `src/components/dashboard/sidebar-nav.tsx`: `{ href: "/dashboard/crm", label: "CRM Imobile", icon: Building2 }`.

## 6. Verificare

- `npx prisma migrate dev` + pornire `npm run dev`
- Register/login, conectare sesiune WhatsApp (QR) — pas necesar înainte de trimitere
- Test manual: adaug client (propria telef.), imobil cu poză → trimit → verific mesajul pe telefon → răspund de pe telefon → răspunsul apare în conversația din aplicație
- Lint/typecheck pe fișierele noi

## Note

- Baileys e neoficial — WhatsApp poate restricționa numere care trimit în volum mare; de aceea trimiterea e secvențială cu delay, potrivită pentru uz individual (nu bulk marketing).
- Restul dashboard-ului rămâne în engleză; pagina CRM va fi în română.
- Presupuneri (adjustabile): moneda implicită EUR (selectabil RON/EUR/USD), prefix telefonic implicit +40.
